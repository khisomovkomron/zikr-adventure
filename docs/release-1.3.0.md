# 1.3.0 — новая структура приложения

Статус: на проверке разработки. Не опубликовано; TestFlight не загружался.

Задача: [ZKR-75](https://zikr-app.atlassian.net/browse/ZKR-75).
План: [Confluence](https://zikr-app.atlassian.net/wiki/spaces/SD/pages/10322024).
Запись выпуска: [Confluence](https://zikr-app.atlassian.net/wiki/spaces/SD/pages/10289282).

Комрон выбрал «Мой день» и разрешил реализацию. Главная показывает краткие обзоры только готовых сервисов: Зикр, Путь Сиры, Карта. Полные экраны открываются из главной или каталога «Сервисы». Третий раздел — «Настройки»: прежние параметры, аккаунт и действия сохранены; Инфо и конфиденциальность доступны отсюда. Добавлено оформление: системное / светлое / тёмное. Будущих сервисов, недоступных плиток и заглушек нет.

## Совместимость

Bundle ID, ключи прогресса, JSON, команды записи и одноразовая legacy-миграция не менялись. Главная подписана на тот же ZikrViewModel, отдельного счётчика/писателя нет. Дата и счётчик дня обновляются при смене дня, часового пояса и возврате приложения.

Новый UserDefaults `app.appearance` хранит только тему. Отсутствующее/неизвестное значение — системная тема. «Настройки по умолчанию» возвращает системную тему; сброс прогресса её не затрагивает.

Версия в project.yml и project.pbxproj: 1.3.0 / build 6. Последний загруженный build по ASC — 5; перед загрузкой перепроверить номер. Это исходники, не доступный TestFlight build. Принятый 1.2.0 (5) не меняется.

Устройство/iOS и результаты пока не зафиксированы. Обязательны:

- Обновление поверх App Store без удаления: прогресс, история, главы, настройки, аккаунт.
