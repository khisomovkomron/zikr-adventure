Комрон выбрал «Мой день» и разрешил реализацию. Главная показывает краткие обзоры только готовых сервисов: Зикр, Путь Сиры, Карта, Кибла. Полные экраны открываются из главной или каталога «Сервисы». Третий раздел — «Настройки»: прежние параметры, аккаунт и действия сохранены; Инфо и конфиденциальность доступны отсюда. Добавлено оформление: системное / светлое / тёмное. Будущих сервисов, недоступных плиток и заглушек нет.

## Совместимость

Bundle ID, ключи прогресса, JSON, команды записи и одноразовая legacy-миграция не менялись. Главная подписана на тот же ZikrViewModel, отдельного счётчика/писателя нет. Дата и счётчик дня обновляются при смене дня, часового пояса и возврате приложения.

Новый UserDefaults `app.appearance` хранит только тему. Отсутствующее/неизвестное значение — системная тема. «Настройки по умолчанию» возвращает системную тему; сброс прогресса её не затрагивает.

Версия в project.yml и project.pbxproj: 1.3.0 / build 7. Последний загруженный build по ASC — 5; перед загрузкой перепроверить номер. Это исходники, не доступный TestFlight build. Принятый 1.2.0 (5) не меняется.
