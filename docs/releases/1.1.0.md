## Ограничения текущей реализации

- **iOS компиляция недоступна на этом VM:** код написан, но не собран. Ошибки компиляции, синтаксические ошибки Swift, опечатки в API могут быть обнаружены только при сборке на Mac/Xcode.
- **Xcode project.pbxproj не обновлён напрямую:** Swift Package dependencies, GoogleService-Info.plist, AuthCoordinator.swift и entitlements файл должны быть добавлены вручную в Xcode (см. XCODE_SETUP.md). project.yml обновлён, можно пересоздать проект через XcodeGen.
- **Account screen HTML/JS UI не реализован:** мост Swift ↔ JavaScript готов, но интерфейс аккаунта в Web/index.html отсутствует. Требуется ZKR-19.
- **Реальная авторизация не проверена:** Sign in with Google, Sign in with Apple, выход, удаление работают только теоретически. Все device tests (ZKR-21) ещё не выполнены.
- **Apple Developer capability не включена:** "Sign in with Apple" для App ID `com.komronkhisomov.zikradventure` должна быть включена владельцем в https://developer.apple.com/account (XCODE_SETUP.md шаг 7).
