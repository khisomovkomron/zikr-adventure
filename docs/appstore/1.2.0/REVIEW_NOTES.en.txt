Version 1.2.0 replaces the previous web interface with native SwiftUI screens. The app can be used as a guest; Google/Apple login is optional. Existing local progress is migrated once when updating. Progress is stored on the device; signing in does not provide cloud progress synchronization. Account deletion is in Settings and requires reauthentication; Apple token revocation completes before deletion. This is the same build 5 accepted in TestFlight.
